# TrabalhoGrupoDEAPC

## Objetivos do Projeto

Desenvolver uma aplicação web que permita:

- Gerir níveis de stock de produtos em tempo real
- Processar encomendas de clientes
- Armazenar e consultar dados de compras
- Acompanhar o estado e o cumprimento das encomendas

---

## Tipos de Utilizadores

Mínimo 2, sugeridos 3:

- Administrador
- Funcionário (responsável do armazém)
- Cliente

---

## Funcionalidades por Utilizador

### Administrador
- Criar/modificar/eliminar produtos
- Ver estatísticas do stock
- Gerir contas dos utilizadores

### Funcionário
- Ver lista de produtos em stock
- Atualizar quantidades (entrada/saída)
- Processar encomendas

### Cliente ou Gestor de Compras
- Fazer pedidos de encomenda
- Ver histórico de encomendas
- Acompanhar estado de entrega
